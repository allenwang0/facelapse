Methodology

How this run was made

facelapse finds every face in each photo and turns it into an ArcFace embedding. A face counts as you when it is similar enough to your seed photos from the same era and beats the next-best face in the photo by the margin. Turned heads, strong expressions, small faces, near-duplicates and photos dated only by file time are then dropped.

Each remaining photo gets a score that blends frontality, neutral expression, sharpness, resolution, identity and open eyes. The best photo per period becomes a frame. Frames are aligned on the eyes, the sequence of alignments is smoothed over a short window, and exposure is evened out before encoding.

Eye offset
Distance in canvas pixels between where a frame's eye midpoint lands and the fixed target. A 2-point fit puts it exactly on target; it moves off only when the nose-bridge landmark pulls the fit.
Jitter
Mean absolute change in eye offset between consecutive frames.
Similarity
Cosine similarity between a face's embedding and the seed photos.

Reproduce

Run it yourself

pip install -e ".[dev]"     # add ".[ml]" for face models on real photos
python tests/fixtures/make_fixtures.py
facelapse seed add tests/fixtures/seeds/*.jpg --backend synthetic
facelapse run tests/fixtures/photos --backend synthetic   # writes out/timelapse.mp4
facelapse report --synthetic   # writes out/report.html

Pixel values vary by platform. The same synthetic run gives slightly different jitter on macOS and Linux, so compare numbers produced on one machine. The environment below produced this page.
